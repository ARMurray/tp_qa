## Operational rules (keep)

- Work on `master`. The owner pushes HPC output back through git; **pull
  before pushing**.
- **No Python on the HPC login node.** Diagnostics ship as a committed script
  + `.slurm` writing to `correction/diagnostics/`; the owner pushes the
  output back. Login shell is **tcsh**.
- `detection/`, `review_app/` and `viewer/` run on the Windows work computer;
  `correction/` runs on the HPC (RHEL, SLURM).
- The owner cannot copy/paste from the work computer: ask for results to be
  pushed to git (or for a short line to be typed), not pasted.
- Reviewer points are final — never snapped or moved by any step.
- 05b only after 01e `--from-queue` finishes; 10 refuses otherwise.
  Detection outputs older than `best.pt` are ignored by 05b, 06b, 01e resume
  and 13.
- The master (`Updates.gpkg`) and `app.db` are binary: commit and push right
  after closing a round.
