## Operational rules (learned the hard way — keep)

- Work on `master`; the user pushes HPC output back through git. **Pull
  before pushing**; announce pushes while the user has HPC steps in flight
  (diverged branches happened once — fix with `git pull --rebase`).
- No Python on the HPC login node (shell-only scripts are fine, e.g.
  `od_freshness_report.slurm`). Login shell is tcsh. Submit each step after
  the previous shows `COMPLETED 0:0` in `sacct`.
- `collect_logs.slurm` with `TRAINING=1` does not collect 01e/05b logs — use
  `PATTERN=`.
- Use `05_run_inference_array.slurm` (the national script now refuses
  `--array`); `merge_05_shards` refuses shards older than the models.
- 05b must run only after 01e `--from-queue` finishes; 10 now refuses a queue
  whose re-rank never saw its detections.
- Detection outputs older than `best.pt` are ignored by 05b, 06b, 01e resume
  and 13.
- When editing via bash heredocs, backticks and `\n` get mangled by the tool
  wrapper — use the file editor for code/docs containing them.
